# Small E-Commerce Web Application

## Project Overview

A small full-stack E-Commerce Web Application developed for learning purposes.

The application supports two types of users:

### USER

A normal customer can:

- Register
- Login
- Browse products
- View product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- Place orders
- View order history
- Logout

### ADMIN

An administrator can:

- Login
- View admin dashboard
- Add products
- Edit products
- Delete products
- View all products
- View customer orders
- Update order status
